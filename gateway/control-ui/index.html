On the iPad

  1. Install the updated remote userscript once in Safari. The published script needs no login.
  2. Save the gateway base URL and device token in Remote AI, then Connect.
  3. Leave “Connect across websites” enabled. New websites allow reads and ask before actions.
  4. Keep Safari visible alongside Claude when asking it to inspect or act.

Stop gateway ends browser automation. This password-protected control page stays available so you can start it again from your iPad.

Website permissions

Every choice allows reading. Permissions apply to the exact website origin.

Ask every time — default
Filling, clicking and same-site navigation each ask for approval in Safari. No Always allow. Existing field values are not disclosed.
Read only
All actions are blocked without a prompt.
Fill and navigate — no clicks
Ordinary fields are filled without asking. Navigation asks each time. All clicks, including search and submit buttons, are blocked.
Full permission — routine actions automatic
Ordinary fills, same-site navigation, links, tabs, disclosures, menus and recognised tour steps run automatically. Submissions, data changes and unclear controls ask individually.

Payment, account-deletion and credential controls stay blocked in every mode. Cross-site navigation is blocked. Local file URLs are not supported by the remote connector; serve local pages over HTTP instead.

Change permissions directly in the website list, then Save settings. Saving restarts the managed gateway automatically and cancels pending actions. Safari may need to reconnect.
